Projeto Power BI Analyst – DIO
Projeto desenvolvido durante o desafio prático de Power BI da DIO.

Objetivo
Reproduzir duas páginas de relatório apresentadas durante o curso e desenvolver uma terceira página utilizando recursos de visualização do Power BI.

Visualizações
- Página 1: Relatório de vendas.
- Página 2: Análise de dados complementares.
- Página 3: Vendas e unidades vendidas por país, lucro por país e lucro por segmento.

Ferramentas utilizadas
- Power BI Desktop

Arquivo
O relatório completo está disponível em formato PDF neste repositório.
